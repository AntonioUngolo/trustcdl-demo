# TrustCDL, demo

Demo navigabile di TrustCDL, il marketplace per scegliere un consulente del lavoro con profili verificati sull'Albo e recensioni solo da clienti reali.

Pagine statiche in HTML e CSS, senza installazioni: si aprono anche con doppio clic.

| Pagina | File |
| --- | --- |
| Indice della demo | `index.html` |
| Home page | `v2-1.html` |
| Lista consulenti | `consulenti.html` |
| Profilo con piano Pro | `consulente-pro.html` |
| Profilo con piano Free | `consulente-free.html` |
| Area del consulente | `area-consulente.html` |
| Prime versioni della home | `v1-morbida.html`, `v1-bianca.html`, `v2-albo.html`, `v2-bianca.html` |

Stile e script condivisi delle pagine interne sono in `assets/`.

Dati di esempio: nomi, prezzi e recensioni sono fittizi. Foto da Unsplash, mappe da OpenStreetMap.
